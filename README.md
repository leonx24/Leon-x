### 🌟 Highlights

- ⚡ **Universal & Plug-and-Play** — Works seamlessly across any game without extra setup.
- 🎨 **CyberNoir UI** — Clean interface with dynamic themes, icons, and collapsible sections.
- 📱 **Mobile Optimized** — Touch-friendly controls, floating toggle menu, and adaptive font scaling.
- 💾 **Config & Favorites** — Save profiles and pin your most-used features to the Quick Access tab.
- 🛡️ **Defensive Design** — Anti-detection safeguards and smooth client-side execution.

### 🚀 Core Modules

| Category | Features |
|:---|:---|
| **Movement** | Fly (with Shift-Sprint), Speed Hack, Jump Power, Infinite Jump, Noclip, Anti-Ragdoll, Server Invisibility, Click TP, Walk on Water |
| **Combat** | Kill Aura (NPC & Player), Hitbox Expander with Wall ESP, Instant Kill, Quick Switch Macro |
| **Player** | Anti-AFK, Anti-Fling, Anti-Void (smart recovery), God Mode, No Fall Damage, Infinite Stamina, Spoofers, Server Hop, Rejoin |

| **Automation & Macros** | Auto-Clicker (live CPS & anti-detection jitter), Macro Recorder with path playback & map presets, Code Auto-Redeemer |
| **Game Specific** | Custom automation suites for *Grow a Garden 2*, *Fish and Monsters*, and more |

### ⌨️ Controls & Keybinds

| Key / Control | Function |
|:---|:---|
| `U` | Toggle UI Window (or tap floating button on Mobile) |
| `Delete` | Panic Key *(instantly disable all features & hide UI)* |
| `F` | Toggle Fly |
| `LeftShift` | Fly Sprint Boost *(2x speed)* |
| `N` | Toggle Noclip |
| `G` | Teleport to Selected Waypoint |
| `C` | Toggle Auto-Clicker |
| `H` | Toggle Hitbox Expander |

### ⚙️ Configuration & Storage

Snapshots and custom configurations are automatically managed:

```
├── configs/       # Saved configuration profiles (.json)
├── waypoints/     # Saved map waypoints
├── macros/        # Recorded movement macros
└── favorites.json # Pinned quick-access features
```
